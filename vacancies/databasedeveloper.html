Database Developer

Database Engineering SQL

Who we need

  • Someone with deep expertise in relational database design and architecture
  • A SQL expert who can write complex queries and optimize database performance
  • A problem-solver capable of troubleshooting database issues and improving efficiency
  • An experienced professional comfortable with database management systems like MySQL, PostgreSQL, or SQL Server

Overview:

The Database Developer will be responsible for designing, developing, and maintaining the databases that support our applications. You will work closely with backend engineers, analysts, and product teams to ensure data is stored efficiently, securely, and reliably. This role involves creating database structures, writing stored procedures, and optimising performance for high‑traffic systems.

This position is ideal for someone who enjoys working with data, solving technical challenges, and ensuring systems run smoothly at scale.

Technical Skills:

  • Proficiency in SQL and experience with relational databases
  • Knowledge of database optimisation, indexing, and query tuning
  • Experience with stored procedures, triggers, and functions
  • Understanding of data modelling and schema design
  • Familiarity with cloud databases or data warehousing is a plus

Qualifications:

  • Previous experience as a Database Developer or similar role
  • Strong analytical and problem‑solving skills
  • Ability to write clean, efficient, and well‑structured SQL code
  • Comfort working in a collaborative, agile environment
